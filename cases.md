# Тест-Кейсы для API Petstore

## CRUD операции для объекта "Pet"

### Позитивные тесты

1. **Создание животного (Create)**
    - Отправить POST запрос на создание нового животного с валидными данными.
    - Проверить, что статус код 200.
    - Проверить, что ответ содержит корректные данные животного.

2. **Получение животного по ID (Read)**
    - Отправить GET запрос на получение животного по-существующему ID.
    - Проверить, что статус код 200.
    - Проверить, что данные животного соответствуют ожидаемым.

3. **Обновление информации о животном (Update)**
    - Отправить PUT запрос на обновление существующего животного с новыми данными.
    - Проверить, что статус код 200.
    - Проверить, что данные животного обновлены корректно.

4. **Удаление животного (Delete)**
    - Отправить DELETE запрос на удаление животного по-существующему ID.
    - Проверить, что статус код 200.
    - Отправить GET запрос на получение удалённого животного и проверить, что статус код 404.

### Негативные тесты

1. **Создание животного с отсутствующими обязательными полями**
    - Отправить POST запрос на создание животного без обязательного поля (например, `name`).
    - Проверить, что статус код 500.
    - Проверить, что сообщение об ошибке соответствует ожидаемому.

## Заказ (Order)

### Позитивный тест

1. **Создание и проверка заказа**
    - Отправить POST запрос на создание нового заказа с валидными данными.
    - Проверить, что статус код 200.
    - Отправить GET запрос на получение заказа по ID и проверить, что данные заказа соответствуют созданным.
